# Jamkin assets

This directory contains Jamelade's project-created JamBun, JamPam, and JamJoe
artwork. Contributors license their contributions and any rights they hold
under GPL-3.0-or-later.

The root images are app sprites, `launcher/` contains launcher tiles,
`animated/` and `animated-hq/` contain the two animation quality levels, and
`source/` directories retain editable source material. All assets are bundled
locally; the app does not download or generate Jamkin artwork at runtime.
